# NOVA — Personal AI Assistant

A browser-based personal AI assistant and experimentation project built to explore agentic workflows, browser-first AI products, and practical assistant UX.

## Overview

NOVA is a portfolio project focused on building a useful AI assistant experience in the browser. It brings together conversational AI, tool-driven actions, memory-like context handling, and interactive features in a single interface.

## What It Shows

- AI product design and interaction flows
- Browser-based application architecture
- Agentic workflow concepts and task-driven UX
- UI/UX design for conversational interfaces
- Tool-enabled assistance patterns
- Real-world experimentation with AI-powered software

## Key Features

- Conversational AI assistant experience
- Browser-first interaction model
- Tool-style workflow patterns
- Memory/context retention concepts
- Image and creative workflow support
- Autopilot-style task assistance patterns

## Tech Stack

- JavaScript
- HTML / CSS
- Browser APIs
- AI API integration
- Frontend state management and UI composition

## Why This Matters for a CV

This project is one of the strongest portfolio pieces because it demonstrates:

- building advanced AI-native applications
- designing user-friendly AI interfaces
- shipping complex browser experiences
- solving product and interaction problems in a real system

## Run Locally

1. Clone the repository
2. Serve the project locally using a lightweight static server
3. Add any required API keys or configuration values if your setup requires them

Example:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
